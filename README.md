# LogicCheck | Number 15 Challenge

[![Live Demo](https://img.shields.io/badge/Live_Demo-Open_Project-2563EB?style=for-the-badge&logo=vercel&logoColor=white)](https://number-15-logic-checker-2-mjs.vercel.app/)

A JavaScript conditional-logic exercise that checks whether either of two entered numbers is 15, or whether their sum equals 15.

## ✨ How it works

The checker evaluates three conditions:

1. The first number equals 15.
2. The second number equals 15.
3. The sum of both numbers equals 15.

The result is displayed as a boolean value and uses a simple green/red visual indicator.

## 🛠️ Built with

- HTML5
- JavaScript
- Logical OR operator
- Strict equality

## ▶️ Run locally

~~~bash
git clone https://github.com/modewika1-star/t10.git
cd t10
~~~

Open `index.html`, enter two numbers, and click **Check**.

## 📁 Files

- `index.html`: numeric inputs and result container.
- `script1.js`: condition checks and result display.
